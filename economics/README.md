## Практика

Начните с предисловия и глав 1–4. Книга содержит маршрут обучения, математический справочник и четыре контрольные работы. В Excel включите автоматический пересчёт; лист NPV рассчитан на пять лет. Суммы, ставки и распределения в примерах условные.

Для Python-практикума:

```sh
python3 practice.py
```

Нужен Python 3; дополнительные пакеты этому скрипту не требуются. Он сохраняет результаты рядом со скриптом в `verified_results.json`.

Проверены 72 численных результата новой книги и 79 формул базового сценария Excel независимыми Python-расчётами. Это учебный материал: действующие налоговые нормы и сведения реального предприятия требуют первичных документов. Перед издательской публикацией нужна независимая предметная рецензия.

Исходная пользовательская рукопись и редакторский отчёт с корпоративными сведениями в этот комплект не включены.
